| 항목 | 재현 전 | 재현 후 |
|---|---|---|
| `HEAD` | `1ea8e33…` | `1ea8e33…` |
| 브랜치 | `main` | `main` |
| 커밋하지 않은 변경 | 0 | 0 |

| 필요한 것 | 어디에 | 비고 |

| Node 24.19.0 | 공식 사이트 | 이 PC의 위치에 의존하지 않음. 풀어 둔 폴더를 PATH 앞에 두는 한 줄만 사용 |

- 옮기지 않는 것: 원래 PC의 계정 연결 설정 폴더(사용자 폴더 아래 `.aleph-keshev-…`), 인증·설정 파일, 키·토큰. 새 환경에서 앱 화면의 계정 연결과 AI 승인을 다시 합니다.

| 데이터 | 위치 | 보존·백업 | 복원 | 제한 |
|---|---|---|---|---|
| 학생 작성 소스·문서 | `student/extension.mjs`, `docs/STUDENT_RUNBOOK.md`, `docs/STUDENT_RELEASE_RECORD.md`, `README.md` | Git 커밋과 GitHub `main` 에 보관(공개 저장소). 커밋·`git push` | `git clone https://github.com/Won-22/safety` 후 `git checkout <커밋>` (3장 1번으로 확인) | 공개 저장소이므로 비밀값을 넣지 않음. 저장소를 지우면 복구 불가. 로컬 커밋은 push 전에는 GitHub에 없음 |
| 제공 시작 틀 | `on-client/` 나머지 | 같은 커밋에 포함됨. 시작 틀 zip은 다운로드 폴더에 있었으나 이 기록의 일부가 아님 | 같은 clone | 시작 틀 업데이트는 제공 문서(`docs/STARTER_UPDATE.md`)의 보존 규칙을 따름. 이 PC에서 실행하지 않음(미확인) |
| 계정 연결 설정 | 사용자 폴더 아래 `.aleph-keshev-<프로젝트 경로의 해시>` 폴더(파일 이름만 확인: `native.json`, `.alekov-native-registry.json`, `.native-history-….bak`. 내용은 열어 보지 않음) | 이 폴더는 프로젝트 폴더 경로마다 따로 만들어지며 저장소에 포함되지 않음 | 복사해서 옮기지 않고 새 환경에서 앱 화면의 계정 연결·AI 승인을 다시 함 | 다시 승인해야 하고, 운영 측 권한이 준비되지 않으면 연결되지 않음 |
| 실행 중 화면 상태 | 브라우저 메모리 | 보존하지 않음 | 해당 없음 | 다시 불러오면 새로 그림 |

- 소스를 읽은 결과, 앱의 쓰기 코드(파일 쓰기)는 포장 도구(`tools/export-student-package.mjs`, `tools/package-app.mjs`)에만 있고 서버 실행 중에는 학생 데이터 파일을 만들지 않습니다(원문 확인). 조치 기록 저장소는 담당자가 기존 데이터베이스 경로를 직접 지정할 때만 쓰이며 기본 실행에는 지정하지 않았습니다(원문 확인, 실행은 하지 않음).
- 수료 패키지 내보내기 도구(`npm run package-app`)는 이 기록에서 실행하지 않았습니다(미확인).
- 백업·복원은 GitHub 저장소 하나에 의존합니다. 별도 백업 사본은 만들지 않았습니다.
